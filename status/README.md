## The routine
1. Finish a task (even a small one).
2. Add an entry at the **top** of your own file:
   ```markdown
   ## 2:15 PM: Done: gold_bar.json pushed
   Next: grandparent.json
   Blocked on: nothing
   ```
3. Commit and push your work together with the status update.
4. Repeat.

If you're stuck for more than 20 minutes, write it under "Blocked on" and push, so the team can see it.
